# 环境变量

默认零配置。规划器读显存、内存、盘速，自己解出层驻留、环大小、缓存容量、prefill
分块。下面这些变量只用于测量、A/B 对比、以及把已验证的机制提上来。**跑起来一个都
不需要设。**

## 规划与容量

| 变量 | 含义 |
| --- | --- |
| TI_TIER | 优化档位 0~3（见 tiers.py） |
| TI_TOPK | 每 token 的路由专家数（0 = 按 checkpoint 的 top-6；调低是拿质量换 IO） |
| TI_GPU_LAYERS | 强制常驻层数，绕过规划器 |
| TI_CHUNK | prefill 分块大小（长 prompt 会自动降档） |
| TI_RING | streaming 环形缓冲数量（2~4，默认由规划器定） |
| TI_RAM_FRACTION、TI_RAM_RESERVE_GB | 主机内存预算的调节旋钮 |
| TI_CACHE_POLICY | 专家缓存策略：arc（默认）或 lru |
| TI_PIN_CACHE、TI_PIN_CACHE_GB | 把部分专家缓存钉住，走直接异步 DMA |
| TI_SLAB、TI_FLAT_PIN_GB | pinned 层块的尺寸 |
| TI_FLAT | 1 强制开启扁平 streaming，0 关闭；不设由规划器决定 |

## 数值与语义

| 变量 | 含义 |
| --- | --- |
| TI_YARN_MSCALE | 1（默认）跟随 DeepInfer 的 yarn_get_mscale；0 对齐纯 HF 表 |
| TI_FUSED_KV | 1 开启融合的 rope+fp8 KV kernel（已验证逐位一致，默认关） |
| TI_BF16_CACHE | 1 让每层最多保留 8 份 bf16 专家副本（吃显存，大卡用） |
| TI_NO_MASK_CACHE | 1 关闭 indexer 的可见性掩码缓存 |
| TI_MULTIROW_GEMV | 1 启用多行 fp4 kernel |
| TI_NO_SLOTS | 1 关闭显存专家槽位池（确定性 logits，但 decode 显著变慢） |
| TI_PREFILL_CHUNK | prefill 的 token 块大小；1 = 与参考实现逐位一致，规划值更快但每层有偏差 |
| TI_REF_ATTN | 1 把稀疏注意力改走 PyTorch 参考实现（诊断用，慢） |
| TI_DEBUG_ATTN | 1 打印压缩层每次调用的分组记录（诊断用） |
| TI_MAX_RESIDENT | 常驻层数上限：显存压力小，但长 prompt 上 argmax 一致率明显下降 |

## 测量

| 变量 | 含义 |
| --- | --- |
| TI_TIME | 每步 decode 计时 |
| TI_MOE_PROF | MoE 分阶段耗时（gate/bincount/serve/fetch/shared） |
| TI_WALL_PROF | 每个 Block 的墙钟分段计时 |
| TI_LAYER_TIME | 每层总耗时 |
| TI_MEM_TRACE | 每层显存分配轨迹 |
| TI_ATTN_PROF | 压缩注意力的分段耗时 |
| TI_HC_DEBUG | Hyper-Connections 中间量 |

## 构建

见 [环境.md](环境.md) 的构建小节与 `scripts/build_native.sh`。编译产物
`kernels/build/*.cubin` 不入库，每次按目标架构现编；提交过期的 cubin 会在别的
架构上报 `cuModuleLoad 209`。
